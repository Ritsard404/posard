# How to Use AI Report Assistant

## What this feature does
AI Report Assistant explains report results in plain language.

## When to use it
Use this when you want help understanding sales, discounts, payment mix, or business trends.

## Before you begin
- You need access to reports.
- Choose a report question you want answered.

## Steps
1. Open **AI Assistant** under Reports.
2. Ask a clear business question.
3. Review the summary and key numbers.
4. Read the suggested actions.
5. Check the source report when you need exact details.

## What happens next
POSard gives a simple explanation based on report information.

## Tips or reminders
- Use AI answers as guidance, not as the official printed report.
- Ask short questions for clearer answers.

## Common questions or issues
- **The answer is too general**  
  Ask about a specific date, report, payment method, or problem.
