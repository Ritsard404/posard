# How to Return Items

## What this feature does
This records items returned by a customer after a sale.

## When to use it
Use this when a customer brings back an item and your store accepts the return.

## Before you begin
- Find the original sale.
- Confirm the store return policy.
- A manager may need to approve.

## Steps
1. Open **Reports** or transaction history.
2. Find the original sale.
3. Open the return option.
4. Select the items being returned.
5. Enter the reason.
6. Confirm the return.

## What happens next
The return is recorded and reports show the returned amount.

## Tips or reminders
- Check the original receipt before returning items.
- Return only the items the customer actually brought back.

## Common questions or issues
- **The sale cannot be returned**  
  It may already be voided, returned, or outside your store policy.
