# How to Void an Item or Order

## What this feature does
This cancels a wrong item or order when it should not be counted as a sale.

## When to use it
Use this for mistakes before or after a sale, depending on your store rules.

## Before you begin
- Know the reason for the void.
- A manager PIN or approval may be required.

## Steps
1. Open the cart or transaction record.
2. Choose the item or order to void.
3. Enter the reason.
4. Ask a manager to approve if POSard requests it.
5. Confirm the void.

## What happens next
The item or order is marked as voided and appears in reports.

## Tips or reminders
- Always enter a clear reason.
- Do not void a sale when a return is the correct action.

## Common questions or issues
- **Approval is required**  
  Ask a manager to review and approve the action.
