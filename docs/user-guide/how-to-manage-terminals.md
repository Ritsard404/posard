# How to Manage Terminals

## What this feature does
This lets managers set up and review POS terminals for a company, including business-type overrides, printer setup, and PIN requirements for session controls.

## When to use it
Use this when adding a terminal, checking status, or updating terminal settings.

## Before you begin
- You need manager or admin access.
- Prepare terminal name, registration details, and business settings.
- Choose whether this terminal should require a manager PIN for opening sessions, cash withdrawal, and closing sessions.

## Steps
1. Open **Terminal List** or **Terminal Settings**.
2. Select an existing terminal or create a new one if allowed.
3. Review the terminal status and details.
4. Update settings such as VAT, discounts, printer, business preset, restaurant options, or **Pinless session controls**.
5. Save changes.

## What happens next
The terminal uses the updated settings in POS and Business Fit guidance. If pinless session controls are enabled, cashiers can open sessions, withdraw cash, and close sessions on that terminal without entering a manager PIN.

## Tips or reminders
- Do not change terminal settings while a cashier is actively selling unless needed.
- Check subscription status if POS access is paused.
- Use terminal overrides for counters such as a repair desk inside a retail store or a dine-in counter inside a cafe.
- Keep pinless session controls off when the store requires manager sign-off for every cash drawer action.

## Common questions or issues
- **A terminal is locked or unavailable**  
  Check if another session is open or billing needs attention.
- **The manager PIN prompt disappeared**  
  Check whether pinless session controls are enabled for that terminal.
