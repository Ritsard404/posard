# How to Print or Reprint a Receipt

## What this feature does
This prints a receipt for a completed sale or prints another copy when needed.

## When to use it
Use this when the customer needs a receipt or the first print did not work.

## Before you begin
- A receipt must already exist.
- A printer should be connected if you need a paper copy.

## Steps
1. Complete the sale or open the transaction record.
2. Open the receipt view.
3. Select the print or reprint option.
4. Choose the printer if POSard asks.
5. Wait for the receipt to print.

## What happens next
The receipt prints or opens as a preview if printing is not available.

## Tips or reminders
- Check that you selected the correct transaction.
- Make sure the printer has paper.

## Common questions or issues
- **The receipt did not print**  
  Check printer connection, paper, and selected printer mode.
