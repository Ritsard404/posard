# How to Use Kitchen Workflow

## What this feature does
Kitchen workflow helps restaurants track orders from queued to served.

## When to use it
Use this for dine-in, takeout, pickup, or delivery orders that need preparation.

## Before you begin
- Restaurant features must be enabled.
- Kitchen staff need access to the kitchen screen.

## Steps
1. Create the order in POS.
2. Send or confirm the order so it appears in the kitchen list.
3. Kitchen staff mark the ticket as preparing.
4. Mark it ready when preparation is done.
5. Mark it served after the customer receives it.

## What happens next
Cashier and kitchen staff can see the preparation status.

## Tips or reminders
- Keep ticket status updated.
- Use notes for food instructions when needed.

## Common questions or issues
- **Kitchen does not show the order**  
  Check if restaurant mode or kitchen tickets are enabled for the terminal.
