# How to Manage Subscriptions

## What this feature does
This shows whether terminals are active, expired, suspended, pending, or informational while POSard is in free mode.

## When to use it
Use this when checking terminal billing status, planning future billing, or fixing POS access after paid mode is enabled.

## Before you begin
- You need manager or admin access.
- Know which company or terminal needs review.

## Steps
1. Open **Subscription** or **Subscriptions**.
2. Find the terminal.
3. Review the status and expiry date.
4. Update or request changes if allowed.
5. If paid mode is enabled, confirm that POS access is restored when billing is active.

## What happens next
In free mode, subscription records are informational and do not block checkout. In paid mode, terminal access follows the updated subscription status.

## Tips or reminders
- POSard is free right now, so expired or suspended subscriptions should not block POS use while free mode is active.
- Expired or suspended subscriptions may block POS use after paid mode is enabled.
- Managers should keep a path to the subscription page to fix billing.

## Common questions or issues
- **Cashiers cannot use POS**  
  Check whether paid mode is enabled, then review terminal subscription status.
