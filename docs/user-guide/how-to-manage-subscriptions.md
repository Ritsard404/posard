# How to Manage Subscriptions

## What this feature does
This shows whether terminals are active, expired, suspended, or pending.

## When to use it
Use this when POS access is paused or when checking terminal billing status.

## Before you begin
- You need manager or admin access.
- Know which company or terminal needs review.

## Steps
1. Open **Subscription** or **Subscriptions**.
2. Find the terminal.
3. Review the status and expiry date.
4. Update or request changes if allowed.
5. Confirm that POS access is restored when billing is active.

## What happens next
Terminal access follows the updated subscription status.

## Tips or reminders
- Expired or suspended subscriptions may block POS use.
- Managers should keep a path to the subscription page to fix billing.

## Common questions or issues
- **Cashiers cannot use POS**  
  Check the terminal subscription status first.
