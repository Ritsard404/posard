# How to Review the Permission Matrix

## What this feature does
The permission matrix shows what each role can access.

## When to use it
Use this when checking what admins, managers, and cashiers are allowed to do.

## Before you begin
- You need admin access.
- Know which role you want to review.

## Steps
1. Open **Permissions** from the admin area.
2. Find the feature or action.
3. Check which roles are allowed.
4. Review sensitive permissions carefully.
5. Use staff account settings if a person's role needs to change.

## What happens next
You can understand which role should be assigned to a staff member.

## Tips or reminders
- Give staff only the access they need for their work.
- Sensitive permissions should stay with trusted roles.

## Common questions or issues
- **A user cannot open a page**  
  Check their role and whether that role has permission.
