# How to Report a Problem or Error

## What this feature does
This guide helps cashiers, managers, and admins send useful bug or error details so POSard support can understand what happened and fix it faster.

## When to use it
Use this when POSard shows an error, a page does not load, checkout does not finish, printing fails, sync needs review, a report looks wrong, or a record appears missing.

## Before you begin
- Stay on the page where the problem happened if it is safe to do so.
- Take a screenshot if the message is visible.
- Do not share passwords, manager PINs, card numbers, or private customer payment details.

## Steps
1. Open **Help Center**.
2. Search for **report**, **bug**, **error**, or **problem**.
3. Open **Report a problem or error**.
4. Select **Contact Support**.
5. Fill in the store, branch, role, page, error message, steps, device, browser, and time.
6. Add receipt, invoice, terminal, or customer references only when they help identify the issue.
7. Attach a screenshot when available.
8. Send the report.

## What happens next
Support can compare the reported page, action, time, and reference against POSard records. Clear reports make it easier to reproduce the problem and decide whether the fix is a setup change, user guidance, or code update.

## Tips or reminders
- Write the exact error message, not only "it failed."
- Include what you expected to happen.
- Mention whether the device was online, offline, slow, or recently refreshed.
- For printer issues, include the printer mode and device model.
- For sync issues, include the Sync Center message and terminal.
- For checkout issues, include the receipt or invoice reference when available.

## Common questions or issues
- **The error disappeared before I copied it**  
  Send the page, time, user, and action. Add what you remember from the message.
- **I am not sure if it is a bug or setup problem**  
  Report it anyway. Include what you were trying to do and what happened.
- **The problem involves a customer**  
  Use the customer name or reference only when needed. Do not send private payment details.
