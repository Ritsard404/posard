# How to Edit Receipt Design and Logo

## What this feature does

This lets managers or admins set the logo and footer message used on receipts for a branch.

## When to use it

Use this when a branch needs its own printed receipt branding, footer message, or logo.

## Before you begin

- Prepare a simple high-contrast logo.
- Use JPG, PNG, or WEBP.
- Avoid tiny text inside the logo.
- Check that the branch and printer settings are correct.

## Steps

1. Open Company.
2. Select Branches.
3. Add or edit a branch.
4. Enter or update the Receipt Footer.
5. Upload, replace, or remove the Receipt Logo.
6. Review the receipt preview.
7. Save the branch.
8. Print a test receipt from POS or a completed sale.

## What happens next

New receipts use the branch logo and footer when available. If the branch has no logo, POSard can fall back to the company logo. Browser receipt preview and browser printing include the logo. Supported ESC/POS and SUNMI thermal printer paths also attempt to print the logo before the receipt text.

## Tips or reminders

- Use a black or dark logo on a white or transparent background.
- Keep the logo wide and simple for thermal paper.
- Test print before using the receipt at the counter.
- Complex images may look faint on thermal printers.

## Common questions or issues

- **The logo does not print on the thermal printer**  
  The printer may not support image output or may reject the image data. POSard continues with the text receipt so checkout is not blocked.

- **The logo looks too light**  
  Upload a darker, simpler version of the image.

- **The wrong logo appears**  
  Check the branch assigned to the terminal and update that branch's receipt logo.
