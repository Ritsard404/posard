# How to Set Up Printers

## What this feature does
This connects receipt printing to the terminal or cashier session.

## When to use it
Use this before selling if receipts need to print automatically or on demand.

## Before you begin
- The printer must be powered on.
- The device must support the selected printer type.

## Steps
1. Open **Printer Setup** or the printer setup option in POS.
2. Choose the printer mode.
3. Connect or select the printer.
4. Print a test or preview if available.
5. Save the printer setting.

## What happens next
Receipts can print using the selected printer.

## Tips or reminders
- Bluetooth printers must be paired or available before printing.
- Built-in Sunmi printing works only on supported devices.

## Common questions or issues
- **The receipt opens as preview only**  
  The printer may not be configured or connected.
