# How to Close a Cashier Session

## What this feature does
This ends the cashier shift and records the counted cash.

## When to use it
Use this at the end of a shift or when handing over the terminal.

## Before you begin
- Finish all active sales.
- Count the cash in the drawer.

## Steps
1. Open **Point of Sale**.
2. Choose the close session option.
3. Enter the counted cash.
4. Review expected and counted amounts.
5. Ask a manager to approve if needed.
6. Confirm closing.

## What happens next
The session closes and the shift can be reviewed in reports.

## Tips or reminders
- Count carefully before closing.
- Explain any cash difference to the manager.

## Common questions or issues
- **The session will not close**  
  Check if there are unfinished actions or if manager approval is needed.
