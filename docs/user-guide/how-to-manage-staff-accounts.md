# How to Manage Staff Accounts

## What this feature does
This lets managers and admins review staff access and account status.

## When to use it
Use this when adding cashiers, updating profiles, or disabling old accounts.

## Before you begin
- You need manager or admin access.
- Know the staff member's correct name, email, and role.

## Steps
1. Open **User Management**.
2. Search or select the staff account.
3. Review the role and status.
4. Update details or access if needed.
5. Save the change.

## What happens next
The staff member's access follows the updated account settings.

## Tips or reminders
- Disable accounts that should no longer access the store.
- Cashiers can usually view their own profile only.

## Common questions or issues
- **A cashier cannot log in**  
  Check if the account is active and has the correct email.
