# How to Set VAT, Discounts, and Restaurant Options

## What this feature does
Terminal settings control VAT, discount limits, and restaurant features for a terminal.

## When to use it
Use this during setup or when the business changes how receipts and orders should work.

## Before you begin
- You need manager access.
- Know whether the terminal is retail, restaurant, or mixed use.

## Steps
1. Open **Terminal Settings**.
2. Choose the terminal.
3. Review VAT settings and discount limits.
4. Turn restaurant features on only when needed.
5. Save the settings.
6. Test a sale or receipt if the change affects checkout.

## What happens next
The terminal follows the updated tax, discount, and restaurant behavior.

## Tips or reminders
- Non-VAT terminals should not show VAT details on receipts.
- Kitchen workflow should stay off for normal retail terminals.

## Common questions or issues
- **Restaurant options do not appear in POS**  
  Check if restaurant features are enabled for the terminal.
