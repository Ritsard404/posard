# How to Add and Update Cart Items

## What this feature does
This lets you adjust the items in the customer cart before payment.

## When to use it
Use this when a customer changes quantity, adds another item, or removes an item.

## Before you begin
- A cashier session must be open.
- At least one item should be in the cart.

## Steps
1. Add products to the cart from the POS screen.
2. Review the item names, prices, and quantities.
3. Increase or decrease quantity as needed.
4. Remove any item the customer does not want.
5. Continue to checkout when the cart is correct.

## What happens next
The cart total updates before payment.

## Tips or reminders
- Always confirm quantity before checkout.
- For products with options, check the selected option before confirming.

## Common questions or issues
- **The total looks wrong**  
  Check item quantity, discounts, and selected options.
