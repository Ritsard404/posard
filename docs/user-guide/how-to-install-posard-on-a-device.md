# How to Install POSard on a Device

## What this feature does
This helps you install POSard on a trusted phone, tablet, Android POS device, or computer.

## When to use it
Use this on devices that cashiers or managers use every day.

## Before you begin
- Open POSard in a supported browser, or open the POSard download page.
- Use a trusted store device.
- Know the device type before downloading: Android uses an APK, while Windows uses an EXE or MSIX only when a Windows installer is available.

## Steps
1. Open the POSard website.
2. Select **Download**.
3. Choose the option for your device.
4. For Android devices, download the **Android app (.apk)** only when it is published on the page.
5. For iPhone, iPad, Windows, Mac, or browser-only devices, use the **Web app / PWA** option.
6. Confirm the browser or device prompt.
7. Open POSard from the home screen, app list, or browser.

## What happens next
POSard opens from the installed Android app, the browser app window, or the normal web login page.

## Tips or reminders
- Android phones, tablets, and SUNMI devices use the APK path when a signed APK is published.
- A Windows EXE or MSIX is not a mobile installer. Use it only on Windows devices after POSard publishes a signed Windows installer.
- If the install button does not appear, use the browser menu and look for install or add-to-home-screen.
- Install POSard only on trusted devices.
- Phones, tablets, and Android app devices use a focused app mode for checkout, sync, printer setup, customers, debts, and help. Use a desktop browser for deeper reports, imports, and company setup.

## Common questions or issues
- **I do not see Install**  
  Refresh the page or check the browser menu.
- **Should I download an EXE for my phone?**
  No. Android phones and tablets use APK-based Android apps. EXE or MSIX files are for Windows only.
- **The APK is not available yet**
  Use the Web app / PWA option until a signed Android APK is published.
