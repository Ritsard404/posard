# How to Install POSard on a Device

## What this feature does
This adds POSard to a phone, tablet, or computer so it opens more like an app.

## When to use it
Use this on devices that cashiers or managers use every day.

## Before you begin
- Open POSard in a supported browser.
- Use a trusted store device.

## Steps
1. Open POSard.
2. Look for the **Install** button in the top bar.
3. Select **Install**.
4. Confirm the browser prompt.
5. Open POSard from the home screen or app list.

## What happens next
POSard opens in its own app window.

## Tips or reminders
- If the install button does not appear, use the browser menu and look for install or add-to-home-screen.
- Install POSard only on trusted devices.

## Common questions or issues
- **I do not see Install**  
  Refresh the page or check the browser menu.
