# How to Manage Customers and Loyalty

## What this feature does
This keeps customer profiles, balances, and loyalty activity in one place.

## When to use it
Use this when tracking repeat customers, customer notes, unpaid balances, or loyalty points.

## Before you begin
- You need manager access for customer management.
- Prepare the customer name and contact details.

## Steps
1. Open **Customers**.
2. Search for an existing customer or add a new one.
3. Review debt balance and loyalty points.
4. Update customer details when needed.

## What happens next
The customer record becomes easier to find for sales, debts, and loyalty review.

## Tips or reminders
- Avoid creating duplicate customer names.
- Use notes only for helpful business information.

## Common questions or issues
- **The customer appears twice**  
  Use the clearer or more complete record and ask a manager before making changes.
