# How to Use the Dashboard

## What this feature does
The dashboard shows important store activity in one place.

## When to use it
Use it at the start of the day, during operations, or before reviewing reports.

## Before you begin
- Sign in to POSard.
- Use a manager account for the full business view.

## Steps
1. Open **Dashboard**.
2. Review the summary cards.
3. Check alerts that need attention.
4. Open the suggested page if a card shows a problem.
5. Use reports for deeper details.

## What happens next
You get a quick view of sales, sessions, stock, debt, subscriptions, or other items that need attention.

## Tips or reminders
- The dashboard is a quick view, not a replacement for reports.
- Review warning cards before the end of the day.

## Common questions or issues
- **Numbers look different from a report**  
  Check the date range and report type.
