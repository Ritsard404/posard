# How to View Sales Reports

## What this feature does
Reports show sales, returns, voids, payments, discounts, and shift activity.

## When to use it
Use reports to review daily performance, check cashier activity, or prepare closing records.

## Before you begin
- You need permission to view reports.
- Select the correct report and date range.

## Steps
1. Open **Reports**.
2. Choose the report type you need.
3. Set the date or filters.
4. Review the summary and transaction list.
5. Print or export if needed.

## What happens next
POSard shows the matching report information.

## Tips or reminders
- Use the correct date before printing.
- Debt collections and sales may appear separately depending on the report.

## Common questions or issues
- **The report looks empty**  
  Check the date, terminal, and report type.
