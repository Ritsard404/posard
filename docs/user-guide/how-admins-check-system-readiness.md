# How Admins Check System Readiness

## What this feature does
System readiness helps admins check whether POSard setup items need attention.

## When to use it
Use this after setup changes, before rollout, or when investigating platform-level problems.

## Before you begin
- You need admin access.
- Know which company, terminal, or setup area you are checking.

## Steps
1. Open the admin area.
2. Open **System Readiness**.
3. Review warnings or missing setup items.
4. Open the related page to fix the issue.
5. Check readiness again after changes.

## What happens next
Admins can see what still needs setup or review.

## Tips or reminders
- Fix critical setup issues before allowing live selling.
- Do not ignore terminal or subscription warnings.

## Common questions or issues
- **A readiness item stays unresolved**  
  Recheck the related company, terminal, or subscription page.
