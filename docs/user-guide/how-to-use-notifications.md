# How to Use Notifications

## What this feature does
Notifications show important items that need attention, such as approvals or system alerts.

## When to use it
Use this when you see a number on the bell icon or want to check recent alerts.

## Before you begin
- Sign in to POSard.
- Look for the bell icon in the top bar.

## Steps
1. Select the bell icon.
2. Read the latest notifications.
3. Open any notification that links to a page.
4. Mark one or all notifications as read when finished.

## What happens next
Unread counts go down and you can follow up on important items.

## Tips or reminders
- Do not ignore action-required alerts.
- Some notifications are only shown to users who can handle them.

## Common questions or issues
- **I do not see a notification someone else sees**  
  Your role or company access may be different.
