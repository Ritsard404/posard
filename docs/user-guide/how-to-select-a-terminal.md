# How to Select a Terminal

## What this feature does
This connects your sale activity to the correct POS terminal.

## When to use it
Use this before starting sales, especially if your store has more than one terminal.

## Before you begin
- Your account must be allowed to use POS.
- The terminal should be active.

## Steps
1. Open **Point of Sale**.
2. Choose the terminal you will use.
3. Confirm the selection if POSard asks.

## What happens next
POSard opens the selling screen for that terminal.

## Tips or reminders
- Make sure you select the correct terminal before selling.
- If the terminal is already in use, ask the current cashier or manager before continuing.

## Common questions or issues
- **The terminal is not available**  
  Ask a manager to check terminal setup or active sessions.
