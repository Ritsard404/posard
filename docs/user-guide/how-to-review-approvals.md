# How to Review Approvals

## What this feature does
Approvals let managers review sensitive actions before they continue.

## When to use it
Use this for actions such as large discounts, voids, expenses, transfers, or account requests.

## Before you begin
- You need manager or admin access.
- Review the request details carefully.

## Steps
1. Open **Approvals**.
2. Review the pending request.
3. Read the reason and action details.
4. Add a note if needed.
5. Select **Approve** or **Reject**.

## What happens next
POSard records the decision. Approved actions can continue. Rejected actions do not continue.

## Tips or reminders
- Approve only when the reason is clear.
- Use rejection notes when staff need to understand what to fix.

## Common questions or issues
- **I do not see the approval**  
  Check if you are signed in with a manager or admin account.
