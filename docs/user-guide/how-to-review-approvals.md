# How to Review Approvals

## What this feature does
Approvals let managers review sensitive actions before they continue.

## When to use it
Use this for actions such as large discounts, voids, expenses, transfers, or account requests.

## Before you begin
- You need manager or admin access.
- Review the request details carefully.

## Steps
1. Open **Approvals**.
2. Review the pending request.
3. Read the reason and action details.
4. Add a note if needed.
5. Select **Approve** or **Reject**.

## What happens next
POSard records the decision. Approved actions can continue. Rejected actions do not continue. For an older pending registration, approval emails the user a secure **Set my password** link so they can choose their own password without contacting the admin.

When a new manager registration is submitted, every active admin also receives an email with a **Review registration** link when email delivery is enabled. The link opens the same approval queue so the request can be handled immediately.

## Tips or reminders
- Approve only when the reason is clear.
- Use rejection notes when staff need to understand what to fix.
- Keep each admin profile email current so registration alerts reach the right reviewers.
- Never create or send a user's password. POSard sends an expiring setup link instead.

## Common questions or issues
- **I do not see the approval**  
  Check if you are signed in with a manager or admin account.
- **The registration approval email did not arrive**
  Check the admin profile email and the system email provider settings, then open **Approvals** directly because the request remains in the queue.
