# Feature Catalog and Guided Examples

POSard now keeps its feature display in one shared catalog used by the public feature page, protected walkthroughs, and SEO feature data.

## Public Reading Path

- `/features` shows POSard features grouped by workflow.
- Each feature card explains what the feature does, the practical benefit, and a sample business outcome.
- The card links to the signed-in Feature Guide and the matching Help Center topic.

## Signed-In Walkthrough Path

- `/feature-guide` is available after login.
- Each feature includes:
  - how it works,
  - sample benefit,
  - sample outcome,
  - Help Center link,
  - live app area link when the route can be resolved for the user's company.

## Help Center Discovery

Users can search the Help Center for terms such as:

- feature guide
- feature catalog
- benefits
- sample outcome
- walkthrough
- how it works

The Help Center entry points users back to `/feature-guide` for the full catalog.
