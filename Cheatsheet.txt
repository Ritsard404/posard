POSARD COMMAND CHEATSHEET
Windows / PowerShell reference for daily development

============================================================
1. BASICS
============================================================

Project folder
  cd C:\Users\richa\Documents\POS\posard

============================================================
2. INSTALL AND SETUP
============================================================

Install dependencies
  npm.cmd install

Generate Prisma client
  npx.cmd prisma generate

Apply production-safe migrations
  npx.cmd prisma migrate deploy

Create a new local migration while developing
  npx.cmd prisma migrate dev --name your_change_name

Open Prisma Studio
  npx.cmd prisma studio


============================================================
3. WEB DEVELOPMENT
============================================================

Start local dev server
  npm.cmd run dev

Start production server after build
  npm.cmd run start

Create production build
  npm.cmd run build

Run full lint
  npm.cmd run lint

Run TypeScript check
  npx.cmd tsc --noEmit

Lint only specific files
  npx.cmd eslint app/(protected)/pos/_components/ReceiptPrintControls.tsx
  npx.cmd eslint capacitor.config.ts src/lib/capacitor/printer-bridge.ts

If a Next.js generated type file looks stale
  Remove .next, then rebuild
  npm.cmd run build


============================================================
4. WEB TESTING
============================================================

Install Playwright browsers
  npm.cmd run test:e2e:install

Run all Playwright tests
  npm.cmd run test:e2e

Open Playwright UI
  npm.cmd run test:e2e:ui

Run Playwright headed
  npm.cmd run test:e2e:headed

Run Playwright debug mode
  npm.cmd run test:e2e:debug

Open Playwright report
  npm.cmd run test:e2e:report

Run one test file
  npm.cmd run test:e2e -- tests/auth/sign-up.spec.ts

Run one folder
  npm.cmd run test:e2e -- tests/product

Run one file with one worker
  npm.cmd run test:e2e -- tests/product/product-management.spec.ts --workers=1

Run one grep target
  npm.cmd run test:e2e -- --grep "new company admin"

Recommended verification flow before shipping
  1. npx.cmd eslint <touched files>
  2. npx.cmd tsc --noEmit
  3. npm.cmd run build


============================================================
5. ANDROID / CAPACITOR
============================================================

Install Capacitor packages
  npm.cmd install @capacitor/core @capacitor/cli @capacitor/android

Add Android platform
  npm.cmd run cap:add:android

Sync Android project after web/native config changes
  npm.cmd run cap:sync

Open Android Studio project
  npm.cmd run cap:open:android

Run Android app from Capacitor CLI
  npm.cmd run cap:run:android

One-time manual init command if ever needed again
  npx.cmd cap init POSard com.posard.app

If Android folder was deleted and must be recreated
  1. npm.cmd run cap:add:android
  2. npm.cmd run cap:sync
  3. npm.cmd run cap:open:android

Local Android testing against emulator
  $env:CAPACITOR_APP_URL = "http://10.0.2.2:3000"
  npm.cmd run cap:sync
  npm.cmd run cap:open:android

Local Android testing against phone on same Wi-Fi
  $env:CAPACITOR_APP_URL = "http://192.168.1.50:3000"
  npm.cmd run cap:sync
  npm.cmd run cap:open:android

Clear temporary Android test URL in current shell
  Remove-Item Env:CAPACITOR_APP_URL

Hosted production URL fallback
  capacitor.config.ts falls back to:
  https://posard.vercel.app


============================================================
6. GIT
============================================================

See current changes
  git status --short

See full status
  git status

Show diff
  git diff

Show diff for one file
  git diff -- app/(protected)/pos/_components/ReceiptPrintControls.tsx

See staged diff
  git diff --cached

Stage one file
  git add package.json

Stage all changes
  git add .

Commit
  git commit -m "your message"

Create and switch branch
  git switch -c your-branch-name

Switch branch
  git switch main

Pull latest changes
  git pull

Fetch without merging
  git fetch

View recent history
  git log --oneline --decorate -n 20

Inspect one commit
  git show <commit_sha>

Unstage one file
  git restore --staged package.json

Discard local changes in one file
  git restore package.json

Never use casually
  git reset --hard
  git checkout -- .

7. PRISMA / DATABASE
============================================================

Generate Prisma client
  npx.cmd prisma generate

Validate schema
  npx.cmd prisma validate

Format schema
  npx.cmd prisma format

Check migration status
  npx.cmd prisma migrate status

Create and apply migration in development
  npx.cmd prisma migrate dev --name your_change_name

Create migration only
  npx.cmd prisma migrate dev --name your_change_name --create-only

Apply existing migrations
  npx.cmd prisma migrate deploy

Pull DB schema into Prisma schema
  npx.cmd prisma db pull

Push schema without migration
  npx.cmd prisma db push

Reset database in development only
  npx.cmd prisma migrate reset


============================================================
8. COMMON POSARD FLOWS
============================================================

A. Normal frontend/backend change
  1. npm.cmd run dev
  2. Edit files
  3. npx.cmd eslint <touched files>
  4. npx.cmd tsc --noEmit
  5. npm.cmd run build

B. Schema change
  1. Edit prisma/schema.prisma
  2. npx.cmd prisma migrate dev --name your_change_name
  3. npx.cmd prisma generate
  4. npm.cmd run build

C. Android shell refresh after config changes
  1. npm.cmd run cap:sync
  2. npm.cmd run cap:open:android

D. Android app testing against local server
  1. npm.cmd run dev
  2. $env:CAPACITOR_APP_URL = "http://10.0.2.2:3000"
  3. npm.cmd run cap:sync
  4. npm.cmd run cap:open:android

E. Before commit
  1. git status --short
  2. npx.cmd eslint <touched files>
  3. npx.cmd tsc --noEmit
  4. npm.cmd run build
  5. git add .
  6. git commit -m "message"
